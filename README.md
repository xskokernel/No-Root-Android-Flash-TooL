# No-Root-Android-Flash-Tool

**不 Root，也能刷。** 一款原生 Android 刷机与设备管理工具 —— 9008 深度刷写、Fastboot 刷写、ADB 设备管理，全部在手机上直接完成，无需解 BL、无需 Root、无需电脑。

---

## 核心：为什么是「免 Root」

传统刷机几乎绕不开 Root 或电脑：要么 root 后进特权环境操作，要么连着电脑敲命令。本工具换了一条思路 ——

**借助手机原生的 USB Host 能力直连设备**，把刷机需要的底层通信直接跑在 App 内，因此：

- **无需 Root**：不解 BL、不装 Magisk、不碰系统分区，普通用户开箱即用
- **无需电脑**：一部手机 + 一根 OTG 线，即可完成全部刷写流程
- **完整链路**：9008 深刷、Fastboot、ADB 三大通道一应俱全

> Root 当然也支持 —— 但它只是**可选项**，而不是**门槛**。这正是本工具与常规刷机方案的差别所在。

## 功能一览

### 9008 深度刷写（免 Root）
通过 USB Host 直连高通的 9008/EDL 端口，完成深度刷机。
掉进 9008、变砖救援、底层救回 —— 不 Root 也能进、也能刷。

### Fastboot 刷写（免 Root）
免 Root 环境下直接进行 fastboot 分区刷写、镜像写入与设备读写。

### ADB 设备管理
设备识别、授权与日常管理，一个 App 全搞定。

### 可选 Root 模式
对已 Root 的设备提供增强模式，满足进阶玩家的更多操作需求。
